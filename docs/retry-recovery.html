当前策略示例

  1. 模型最多 3 次请求，默认本地退避从 1.5 秒开始。
  2. 服务端建议比本地等待更长时，尊重服务端建议。
  3. 建议超出该操作等待上限时，结束自动重试。
  4. 模型重试撤回本轮临时输出，保留已完成工具。
  5. 重连前检查持久任务状态，完成后直接恢复结果。
  6. 取消终止尚未完成的请求与退避；创建结果未确认时先取得 run_id 再停止。

各类操作的恢复边界

场景恢复方式界面可见状态
模型输出中断重试本轮，撤回本轮临时输出等待 → 正在请求 → 恢复 / 停止
摘要批次失败只重试当前批，完整成功后推进快照上下文压缩 + 次数与倒计时
SSE 断开查持久状态，按 after 序号补拉恢复实时输出 + 倒计时
创建 / 确认结果 / 停止同一幂等键或同一 run_id操作类别 + 请求次数
