01 / 触发

预算接近阈值

首发控制输出大小，后续仅追加正常消息。未达到阈值时不改写历史正文。

02 / 重建

从过程提炼任务状态

保留目标、约束、决策、进度和待办。历史原文从活动输入中退出。

03 / 续接

必要资料按需取回

保留当前请求、错误、图片、待答和最新回读。正文需要时取回，写入前重读当前版本。

没有统一的“顶尖压缩率”
本项目采用首次输出外置、窗口内追加、阈值处深度交接与精确回读；后台预计算、供应商专有加密状态和每批二次核查未直接迁移。它们需要额外并发一致性或供应商能力。

证据边界
Claude Code 仅引用公开工程文章，不声称读过私有核心。样例使用确定性摘要器；真实模型的约束保留、重复回读、编辑正确率、延迟与费用仍需专项评估。

评估 / 尚未完成

缓存条件 ≠ 实际命中率

真实收益需要累计未缓存输入、读写缓存费用、摘要费用与首 token 延迟。当前独立压缩请求尚不复用主模型缓存。
